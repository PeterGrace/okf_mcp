# M4 Task 5: `mcp`: the server handler, the tool context, errors and `list_catalogs` (2026-11-03T00:48:55Z)

Issue #69, Task 5 of `docs/superpowers/plans/2026-11-02-okf-mcp-m4-read-only-server.md`
(milestone 4, epic #64).

## Added

- `Cargo.toml`: `rmcp` 3.8.0 (`server`, `macros`, `transport-streamable-http-server`;
  no default features) and `schemars` 1.2.3.
- `src/error.rs`: `OkfError::kind` (the variant's name), `is_internal` (database and
  migration failures) and `to_json` (`{"error", "message"}` plus the `path`, `catalog`
  or `problems` the error concerns; an internal error's message only says the server log
  has the details). Two tests.
- `src/mcp/mod.rs`: `OkfServer`, the rmcp `ServerHandler` (`#[tool_handler]` over a
  router stored at construction; `get_info` names the crate and version and gives the
  instructions text). `OkfServer::tools` joins each tool module's router; this task has
  one, `catalogs_router`. `OkfServer::context` builds a call's `ToolContext` with its
  error already a tool result. `ToolResult`, `tool_error` (logs internal errors; the
  others at debug level, by kind only),
  `reply` and `blocking` (`spawn_blocking`, re-raising a panic). Three tests.
- `src/mcp/context.rs`: `ToolContext`: the principal, the connection's catalogs and one
  `Arc` of the catalog map per call, with `select`, `states`, `read_set` and `one`
  (Decision 1). `from_parts` reads the principal the auth layer put in the request's
  extensions; a request without one is `Forbidden`. One test.
- `src/mcp/catalogs.rs`: the `list_catalogs` tool and `CatalogInfo`/`CatalogList`
  (name, description, file count, last change of each reachable catalog; the
  connection's selection and write target, or the selection error). Three tests.
- `src/mcp/testing.rs` (test only): `TestApp`, `app_with`, `files`, `principal`,
  `context`, for the tool tasks.

## Notes

- rmcp's `#[tool]` macro finds a tool's output schema by reading `Json<...>` in the
  written return type. Through the `ToolResult<T>` alias the plan used, `list_catalogs`
  was listed without an output schema; every `#[tool]` method now writes
  `Result<Json<T>, CallToolResult>`. `ToolResult` remains as `reply`'s return type.
- `ToolResult`, `tool_error` and `reply` are `pub`: `reply` has no caller until Task 7,
  and an unused `pub(crate)` function fails `clippy -D warnings`.
- `OkfServer` does not derive `Clone`; rmcp needs none.
- `OkfServer::context` and `reply` allow `clippy::result_large_err`: `CallToolResult`
  is over 200 bytes, and rmcp fixes it as a tool's error type.
- Test counts: 314 unit tests (9 new here), 6 golden parity, 1 roundtrip, 12 doc tests.
