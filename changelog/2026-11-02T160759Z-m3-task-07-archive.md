# M3 Task 7: `archive`: tarballs and directories, with the import rules (2026-11-02T16:07:59Z)

Issue #43, Task 7 of `docs/superpowers/plans/2026-11-02-okf-mcp-m3-storage.md`. Pure
reading and writing of catalog files, for `import` (Task 8) and `export` (Task 9). No
database.

## Added

- `archive::read_tarball(input, max_bytes)`: reads a `.tar.gz` into `archive::Files`
  (path to `StoredFile`, sorted). Skips the pax global header `git archive` writes and
  directory entries. Refuses the whole import with `OkfError::ImportRefused`, listing
  every problem at once: symlinks, hardlinks, devices, FIFOs and other non-regular
  entries; names that are not UTF-8, empty, absolute, contain `..` or are not in normal
  form (`./a`, `a//b`, a trailing `/`); duplicate paths; and every file that is also
  another file's directory (`a` beside `a/b.md`). The execute bit is `mode & 0o111`.
  The cap counts the decompressed stream (long-name and pax payloads included), so a
  small upload cannot expand without bound; input that is not a `.tar.gz` is refused
  with a one-line problem.
- `archive::read_directory(root, max_bytes)`: every file of M1's `list_files` contract
  (dotfiles such as `.claude/` and `.gitattributes` kept), except a `.git` file and
  anything under `.git/`, `.worktrees/` or `__pycache__/`. Each file is read once,
  bounded by the remaining budget, so an oversized file is refused without being read
  whole.
- `archive::write_tarball(out, files)` and `archive::ExportFile`: a `.tar.gz` with no
  top-level directory, modes 0644/0755, each file's modification time, and GNU long-name
  entries for paths past ustar's limits.
- `OkfError::ImportRefused { problems }`.
- `okf::workspace::files_that_are_directories` (`pub(crate)`): the file-and-directory
  clash check, shared by `archive` (lists all) and `MemWorkspace::from_stored` (refuses
  on the first).
- Dependencies: `tar` 0.4.46, `flate2` 1.1.10.
- Tests: `an_export_reads_back_exactly`,
  `git_archive_extras_are_skipped_and_modes_decide_the_execute_bit`,
  `every_bad_entry_is_listed_and_the_import_refused`,
  `every_file_that_is_also_a_directory_is_listed`, `the_cap_counts_uncompressed_bytes`,
  `garbage_is_not_an_archive`, `a_directory_reads_every_file_but_git_and_caches`,
  `a_directory_exactly_at_the_cap_is_read`.
