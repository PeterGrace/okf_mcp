# M3: storage (2026-11-02T17:37:03Z)

Milestone 3 of the OKF MCP server (design:
`docs/superpowers/specs/2026-10-26-okf-mcp-server-design.md`, revised for Postgres storage
in PR #36; plan: `docs/superpowers/plans/2026-11-02-okf-mcp-m3-storage.md`, PR #37; epic
#38). Catalogs now live in Postgres: schema and migrations, import from a directory or
tarball, export as a tarball, `catalog` and `key` administration, and a per-catalog
in-memory snapshot rebuilt and swapped when the catalog changes, with lint reading
revision times. Export then import reproduces the real catalog's file contents and
modes byte for byte. Still no server: that is M4.

## Decisions and notes

- **Directory imports stay lenient** (pgrace's decision, review of PR #54): a directory
  is read through M1's listing contract, so a symlink inside the catalog is flattened, and
  a dangling or outside symlink, a special file and a non-UTF-8 name are skipped with a
  warning rather than refused (documented in `src/archive.rs`).
  `git archive --format=tar.gz HEAD | okf-mcp import NAME -` is the exact path.
- **Deadlock note for M5** (Brooke, review of PR #55; the plan's deferred table):
  `catalogs::delete` holds the catalog row `FOR UPDATE` while it locks the open
  changesets, so M5's write path must take `catalogs::lock` before touching changesets,
  or touch the catalog row (or create the changeset) before writing entries, or retry on
  SQLSTATE `40P01`.
- **Open question for M5** (#50): the design's read-only machinery list
  (`AGENTS.md`, `CLAUDE.md`, `README.md`, `tools/`, `.claude/`, `.git*`) does not include
  `install/` or the root `docs/` and `tests/`, which `okf.py` now skips. Recorded in the
  design's "What M3 shipped differently".
- **Lint's commit time is the last revision time**, so after a first import it is the
  import time, and `generated-after-commit` cannot flag a stamp that falls between the
  real git commit and the import.
- **Import skips unchanged files**, so a later change to `Derived::of` needs a backfill
  (review of PR #56).
