# M2 Task 12: parity for the analyses (2026-10-27T16:20:20Z)

Issue #14, Task 12 of `docs/superpowers/plans/2026-10-27-okf-mcp-m2-analysis.md`. Extends
M1's differential harness to `links`, `oldest`, `sprawl`, `lint` and the secret scan,
with goldens for a synthetic corpus and a runtime-built secrets corpus, and live parity
on the real catalog with real git.

## Added

- `tests/parity/okf_shim.py`: an `analysis ROOT NOW COMMITS` command. It runs
  `okf.py`'s own CLI (`links --json`, `oldest --json -n 1000000`,
  `oldest --json --open-questions`, `sprawl --json -n 1000000`, `lint --json`) with
  `now_utc` frozen and `last_commit_times` replaced by a commit-times file, `none`

- `tests/parity.rs`:
  - `rust_analysis`: the same five reports from `Snapshot::build`, `links_report`,

  - `git_commit_times`: a port of `okf.py`'s `last_commit_times` for the live test.
  - `secrets_corpus`: one hit per secret rule plus near misses (glued prefix, a 17th

    dot-directory file,

  - Tests: `analysis_matches_golden`, `secrets_match_golden`, and the ignored

## Notes

- **Non-ASCII JSON is compared as parsed values.** `json.dumps` escapes non-ASCII
  (`\u2082`) and serde_json writes it raw. The shim prints ASCII-only JSON, both sides
  are parsed into `serde_json::Value` and compared recursively, so escaping never
  matters; key order is checked separately and an integer never equals a float. The
  goldens are written by serde_json and hold raw UTF-8 (`analysis.json` does).
- No fixture has a list or mapping `status` (`okf.py` raises `TypeError`; the port
  reports it, a documented divergence in `src/okf/analysis/lint.rs`).
- `okf.py` ran on Python 3.14.4 (sprawl parity needs 3.12+ `sum()`).
- Real catalog (`pg_knowledge_catalog` at `01eaa78`, real git): equal JSON for all five
  reports; lint gives 0 errors and 3 warnings (all `sprawl`), the fresh baseline of
  verified fact 9. Rust took 146 ms for all five reports in release mode (834 ms and
  884 ms in two debug-build runs); `okf.py` through the shim took 2.8 s; `okf.py lint --json` alone 0.22 s.
- `secrets.json` holds only masked values (`ghp_...`) and the rule descriptions.
  `okf.py`'s `scan_secrets` finds nothing in any file this change commits. The plan's
  corpus key `Client_Secret` became `CLIENT_SECRET`: the finding message puts the quoted
  key right after the word `secret` and a colon, so the committed golden itself matched
  the assignment rule (a 12+ character mixed-case value).
- Gates: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`
  (204 unit, 6 parity golden with 6 ignored, 16 doc), `cargo doc -D warnings`, and live
  parity (6 passed).
