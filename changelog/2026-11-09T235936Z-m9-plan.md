# M9 plan: web console

## Added

- `docs/superpowers/specs/2026-11-09-okf-webui-design.md`: the design of a browser
  console for `okf-mcp` and the `/api/v1` JSON API it runs on. It covers API key
  management, health dashboards, catalog administration with import and export,
  maintenance findings and runs, changeset housekeeping, and read-only browsing and
  search.
- `docs/superpowers/plans/2026-11-09-okf-mcp-m9-web-console.md`: the plan for
  milestone 9, in 8 tasks:
  - Task 1, the foundation;
  - Tasks 2 to 7, one feature area each (keys, health, browse and search, catalogs
    and import/export, findings and runs, changesets), which can run in parallel after
    Task 1;
  - Task 8, release 0.12.0.
- `.gitignore`: `.superpowers/` (local brainstorming files).

## Notes

- The decisions and the deviations from the design are in the plan's "Decisions
  taken while planning (2026-11-09)" and "Simplifications and deviations relative to
  the design".
- The browser tests use `rustwright` (a native Rust Chromium driver), so the project
  needs no Node toolchain.
