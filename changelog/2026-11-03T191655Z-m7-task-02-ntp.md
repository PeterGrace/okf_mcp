# M7 Task 2: `ntp`, an SNTPv4 client (2026-11-03T19:16:55Z)

Issue #141, Task 2 of `docs/superpowers/plans/2026-11-03-okf-mcp-m7-deployment.md`
(milestone 7, epic #139).

## Added

- `src/ntp.rs`: a hand-written SNTP client (RFC 4330, NTP version 4) with no new
  dependency. `query(server, clock, timeout)` resolves the server (port 123 unless it
  names one), sends one 48-byte version-4 client packet from a connected UDP socket and
  returns a `Reading { stratum, offset, round_trip }`. One `tokio::time::timeout`
  bounds the whole exchange, DNS included. Both of our times come from the injected
  `Clock`, so tests are exact.
  - **Formulas** (RFC 4330 section 5): offset `((t2 - t1) + (t3 - t4)) / 2`, round
    trip `(t4 - t1) - (t3 - t2)`.
  - **Era rule** (RFC 4330 section 3): a timestamp whose top seconds bit is clear is
    read as era 1 (2036 to 2104), so the client keeps working past February 2036.
  - **Rounding:** both conversions round to nearest, so an instant survives
    `to_ntp`/`from_ntp` exactly; a fraction within half a nanosecond of the next
    second carries into the seconds.
  - **Reply checks:** at least 48 bytes, mode 4, leap indicator not 3, stratum 1 to 15
    (0 is a kiss-o'-death), our originate timestamp, and non-zero receive and transmit
    timestamps (a zero would read as 2036 and give a decades-long offset).
  - **Errors:** `NtpError::{Resolve, NoAddress, Io, Timeout, BadReply}`, each naming the
    server.
  - `#[cfg(test)] pub(crate) mod testing`: `StepClock` (returns given instants in order)
    and `fake_server(times, stratum)`, a one-shot server on 127.0.0.1. Task 3's tests
    use both. No test queries a real NTP server.
  - 9 unit tests.
