# M2 Task 8: `okf::analysis::oldest` (2026-10-27T15:22:37Z)

Issue #10, Task 8 of `docs/superpowers/plans/2026-10-27-okf-mcp-m2-analysis.md`. Ports
`okf.py`'s `AT_RE`, `_ats`, `describe` and `cmd_oldest` (1143-1233) over the snapshot,
so `oldest` gives the same JSON as `okf.py oldest --json` (with `-n` and
`--open-questions`).

## Added

- `src/okf/analysis/oldest.rs`:
  - `oldest(&Snapshot, now, OldestQuery)`: non-deprecated concepts ordered by their
    newest `generated`/`verified`/`reviewed` stamp (never-touched concepts first, at the
    epoch; ties by path), each with title, status, `last_touched` (`+00:00` written
    `Z`), the field it came from, `age_days`, `stale` (`stale_after` passed) and the
    queued `open_questions` as Python's `str()`.
  - `OldestRow` (keys in `okf.py`'s order; the sort key is `#[serde(skip)]`) and
    `OldestQuery` (`Default` is `okf.py`'s `-n 5`).
  - The regex fallback for unparseable frontmatter (`AT_RE` over each field's block,
    `_fm_fallback` for the scalars), with `\b` emulated by a consumed character.
  - `pub(crate) round_one`, Python's `round(x, 1)`, for Task 9 (sprawl).
  - Concepts are described in parallel with `rayon`; `-n` partitions with
    `select_nth_unstable_by` and sorts only the kept rows, and `--open-questions`
    filters before sorting.
- Tests: 7 in `analysis::oldest::tests`: the plan's four, plus `quirks_match_okf_py`,
  `invalid_fallback_dates_are_skipped` and `round_one_rounds_like_python`.

## Changed

- The plan's Task 8: a dated correction note describing the shipped structure.

## Notes

- **Divergences** (module docs): naive timestamps are ignored and a naive `stale_after`
  is never stale (`okf.py` raises `TypeError`); a fallback `at:` value that `AT_RE`
  matches but that is not a date is skipped (`okf.py` raises `ValueError`).
- **Quirks kept**: `okf.py`'s str-only `get`, so a non-string `at`, `title`, `status` or
  `stale_after` counts as missing; a scalar `open_questions` gives none;
  `replace("+00:00", "Z")` turns a `+00:00:30` offset into `Z:30`.
- **Oracle checks.** Every expectation was produced by `okf.py`'s `cmd_oldest`, loaded
  with `importlib` under `python3 -I` with `now_utc` frozen, on the same files written
  to a scratch catalog.
- **Parity** (a throwaway example binary, not committed; `now` pinned to the same
  instant on both sides; `-n 1000000`, `-n 5` and `--open-questions`): the JSON values
  equal `okf.py oldest --json` on `tests/fixtures/catalog` (36 rows) and on
  `pg_knowledge_catalog` at `071e516` (143 rows). The text is byte-identical except on
  the fixture's non-ASCII title, which `json.dumps` escapes (`ë`) and serde_json
  writes raw; Task 12 settles output encoding.
- No public name or signature differs from the plan, so Tasks 9-14 need no edits.
