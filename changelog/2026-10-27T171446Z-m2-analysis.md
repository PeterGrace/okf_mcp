## Added

- `Workspace::list_files`: every regular file except under `.git` and `.worktrees`, in
  `os.walk` order, for the secret scan.
- `okf::pystr` helpers: `py_repr_str`, `py_repr`, `py_repr_opt`, `py_str`, `py_truthy`,
  `ignorecase_literal` (`re.escape` plus Python's `re.I` folding of `i`), `py_unquote`.
- `okf::timestamp`: `PyDateTime`, `parse_iso` (a byte-level port of CPython 3.14's C
  `fromisoformat`, quirks included), `IsoFormat::to_string_iso`, `is_iso_timestamp`.
- `okf::analysis`: `Finding`, and `secrets::scan_secrets` (`SECRET_RULES`, `ASSIGN_RE`,
  `_literal_secret`, `_mask`), with Python's lookarounds emulated for the `regex` crate.
- `okf::snapshot`: `Snapshot::build(&dyn Workspace)` reads and parses every document in
  parallel (`rayon`), then indexes paths, anchors, backlinks, search fields and the secret
  findings of every file except `tools/okf.py`.
- `okf::analysis::links::links_report`, `oldest::oldest`, `sprawl::{sprawl, sprawl_of}`,
  `lint::lint` (with `CommitTimes` as an input): `okf.py`'s `links`, `oldest`, `sprawl`
  and `lint --json`, keys in the same order.
- `okf::search::search`: ranked search within one snapshot (plan decision 3), with type,
  tag and status filters and an `Ord` rank key for M3's cross-catalog merge.
- Parity: the shim's `analysis` command, the `tests/fixtures/catalog/analysis/` corpus,
  `tests/fixtures/commit-times.json`, a runtime-built secrets corpus (no secret-shaped
  string is committed), goldens `analysis.json` and `secrets.json`, and live parity on the
  real catalog with real git.
- `tests/smoke.rs`, `README.md`.

## Divergences from `okf.py` (kept on purpose)

From the plan, each documented in the module that has it:

- A naive timestamp in `oldest` is ignored and a naive `stale_after` is never stale
  (`okf.py` raises `TypeError`); a fallback `at:` value that is not a date is skipped
  (`okf.py` raises `ValueError`).
- A list or mapping `status` is reported with its `repr` (`okf.py`'s lint raises
  `TypeError`).
- ISO week dates and fractional-second offsets are rejected (`okf.py` accepts them);
  whole-second offsets parse, as in Python.
- A link whose target escapes the catalog root is always broken.
- Symlinks follow M1's listing contract; non-UTF-8 file names are skipped.

Added during execution:

- The root `AGENTS.md`, `CLAUDE.md` and `README.md` are in the snapshot but outside the
  link graph; `resolve_concept` only finds snapshot documents (not a dot-directory file)
  (issue #8).
- Sprawl scores equal `okf.py`'s only on Python 3.12 or later, whose float `sum()` is
  compensated; the port reproduces that sum (issue #11).
- Parity compares parsed JSON values, not bytes: `json.dumps` escapes non-ASCII and
  serde_json writes it raw (issue #14). Key order is checked separately, and an integer
  never equals a float.
