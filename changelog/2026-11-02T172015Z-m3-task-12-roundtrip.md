# M3 Task 12: Round trips: the synthetic corpus and the real catalog (2026-11-02T17:20:15Z)

Issue #46, Task 12 of `docs/superpowers/plans/2026-11-02-okf-mcp-m3-storage.md`. The
milestone's acceptance check: import then export reproduces a catalog's files exactly
(content and execute bit), and importing the export again with `--replace` changes
nothing.

## Added

- `tests/roundtrip.rs`, with one helper, `round_trip`: import into a new catalog,
  `store::export::export` into a `Vec<u8>`, `archive::read_tarball` it back, and import
  that with `replace: true`.
  - `the_synthetic_corpus_round_trips` (every `cargo test`): `tests/fixtures/catalog`
    read with `archive::read_directory`, plus an in-memory executable
    `tools/check.sh`. The export equals the input and the second import reports
    0 added, 0 updated, 0 deleted, every file unchanged. It also asserts that the
    files under the root `install/`, `docs/` and `tests/` directories (skipped by the
    markdown walk only) are read, so they round-trip too.
  - `the_real_catalog_round_trips` (`#[ignore]`): `git -C $OKF_PARITY_CATALOG archive
    --format=tar.gz HEAD`, read in memory and never copied into this repository. It
    checks that every tracked file (`git ls-files -z`) is imported and that some are
    executable, then that the export equals the input and the second import reports
    0 added, 0 updated, 0 deleted, every file unchanged. Run:
    `OKF_PARITY_CATALOG=~/repos/pg_knowledge_catalog cargo test --test roundtrip -- --ignored`.
