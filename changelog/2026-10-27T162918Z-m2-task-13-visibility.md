# M2 Task 13: tighten visibility (2026-10-27T16:29:18Z)

Issue #15, Task 13 of `docs/superpowers/plans/2026-10-27-okf-mcp-m2-analysis.md`. The M1
follow-up from the final review: items only the crate itself uses are no longer part of
the library's public API, and the in-memory test double is compiled only for tests.

## Added

- `Cargo.toml`: a `test-util` feature (off by default). With it, other crates and this
  crate's integration tests can use `okf::workspace::MemWorkspace`.

## Changed

- `okf::workspace::MemWorkspace`, its two `impl` blocks, the helpers only it uses
  (`has_key_with_prefix`, `in_dot_directory`, `in_skipped_directory`) and the imports
  only they use (`BTreeMap`, `Bound`, `RwLock`, `paths::dirname`) are behind
  `#[cfg(any(test, feature = "test-util"))]`. The default library and binary no longer
  compile them.
- `okf::pystr` is `pub(crate) mod pystr`. Its items stay `pub` inside the module, so
  the crate can call them, but nothing outside it can.
- `yaml::parse_value`, `yaml::NumberedLine` and `doc::Doc::frontmatter` are
  `pub(crate)`. The raw frontmatter lines' only non-test reader is `analysis::oldest`.
- The four `pystr` doc examples (`universal_newlines`, `py_repr_str`,
  `ignorecase_literal`, `py_unquote`) moved into `pystr`'s unit tests with their
  assertions. A doc test compiles as a separate crate, so it cannot see crate-private
  items. That leaves 12 doc tests, down from 16. The unit-test count is unchanged at 204,
  because the assertions joined existing tests.
- Public docs that linked to the now-private items (`Workspace::read_text`, the
  `markdown` module doc, `doc::Block`, `doc::SeqItems`) name them in plain code instead.
  `rustdoc::private_intra_doc_links` rejects those links under `-D warnings`.
- The plan's Task 13: a dated correction note listing the above.

## Notes

- Nothing was dead. `cargo clippy` with `--lib` and with `--all-targets`, each with and
  without `--features test-util`, reports no unused item, so nothing was deleted.
- No integration or doc test uses `MemWorkspace` (`tests/parity.rs` reads catalogs from
  disk), so no test target needs the feature, and plain `cargo test` still runs
  everything.
- The public surface is unchanged for `tests/parity.rs`, the remaining doc tests, Task
  14's smoke test and M3's planned tool layer: snapshot, analyses, search, workspace
  (`Workspace`, `DiskWorkspace`), doc, yaml values and rendering, markdown, paths, clock,
  timestamp and error.
- Gates: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`
  (204 unit, 6 golden with 6 ignored, 12 doc), `RUSTDOCFLAGS="-D warnings" cargo doc
  --no-deps`, and live parity (`OKF_PARITY_CATALOG=~/repos/pg_knowledge_catalog cargo
  test --test parity -- --ignored`: 6 passed, catalog at `01eaa78`).
