## Added

- `docs/operations.md`, the operator guide, generic (`example.com` names, "the site's
  object store"), in the plan's ten sections: what runs; the image; configuration;
  Postgres; Kubernetes; first run; health and time; upgrades; backup and restore;
  troubleshooting.
  - **Configuration:** every key with its default, including `time_server`, which is refused when
    blank or padded with whitespace. The environment covers `DATABASE_URL`, `OKF_MCP_CONFIG`,
    `OKF_MCP_LISTEN`, `PGSSLMODE`, `PGSSLROOTCERT` and `RUST_LOG`; leave `RUST_LOG` unset for
    the default `warn,okf_mcp=info,tower_http=info`. On IPv6 or dual-stack clusters, listen on
    `[::]:8080`.
  - **TLS:** with a TLS backend compiled in, sqlx's default `sslmode=prefer` tries TLS
    without verifying it. `PGSSLMODE=verify-full` plus `PGSSLROOTCERT` turn verification
    on, and the URL must not name `sslmode` or `sslrootcert`, since URL parameters override
    the environment. A developer with `verify-full` exported sees the plain database tests fail.
  - **Image:** `ghcr.io/petergrace/okf-mcp:<version>` and `sha-<short>`, no `latest`,
    uid 10001. The base images are floating tags on purpose, so never rebuild an old tag.
  - **Kubernetes:** a complete Cluster, ConfigMap, Deployment, Service and Ingress example.
    The Deployment runs one replica with `Recreate`, Decision 10's probes, a non-root,
    read-only root with every capability dropped, an `emptyDir` on `/tmp`, and only `ca.crt`
    mounted from the CA secret. The ingress turns buffering off, sets 3600 s timeouts for
    `/mcp` streams, and allows an 80m body (above `max_import_bytes` plus slack), with the
    reason for each.
  - **`/healthz`:** `clock` is coarse (`ok`, `checked_at`, `offset_ms`, `stratum`). The server
    name and errors go only to the logs, and the clock never changes the status.
  - **Backup:** the barman-cloud plugin covers the ObjectStore, a ScheduledBackup, an
    on-demand backup, and a restore into a new Cluster with no `plugins` section. The export
    route makes an extra copy.
- README: a "Running it" section linking the guide. The `/healthz` route row now shows
  `clock`, the config example has `time_server`, and the load-time refusals include it.
