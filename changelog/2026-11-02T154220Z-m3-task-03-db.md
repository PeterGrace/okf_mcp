# M3 Task 3: `db`: schema, migrations and the test database (2026-11-02T15:42:20Z)

Issue #39, Task 3 of `docs/superpowers/plans/2026-11-02-okf-mcp-m3-storage.md`. The
whole schema of the design's "Storage" section as one embedded migration, the pool and
migrator, and the throwaway Postgres every later database test uses.

## Added

- `migrations/0001_schema.sql`: `server_state` (one row, `admin_generation`),
  `catalogs`, `documents`, `api_keys` (`default_catalog_id` references `catalogs`,
  `ON DELETE SET NULL`), `key_catalogs`, `changesets` (with the partial unique index
  `changesets_one_open_per_session`), `changeset_entries` and `revisions` (unique on
  `(catalog_id, path, revision)`, its primary key, named
  `revisions_catalog_id_path_revision_key`). Every catalog-owned row cascades on
  delete; no column defaults to `now()`. After review of PR #49, every foreign key a
  catalog or key delete looks up has an index (`changesets_catalog_id`,
  `changesets_key_id`, `key_catalogs_catalog_id`, `api_keys_default_catalog_id`,
  `revisions_changeset_id`), so a cascade or `SET NULL` never scans a whole table.
- `src/db.rs`: `MIGRATOR` (`sqlx::migrate!("./migrations")`, embedded at compile
  time), `connect(url)` (a pool of up to 8 connections), `migrate(pool)`, and the
  unit-test helper `test_db()` (a migrated throwaway database).
- `build.rs`: `cargo:rerun-if-changed=migrations`, so a new migration file rebuilds
  the crate (checked: adding `migrations/0002_probe.sql` recompiled `okf_mcp`).
- `tests/support/{mod.rs,pg.rs}`: `TestDb::start()` runs a `postgres:17-alpine`
  container through `testcontainers-modules` and connects a pool; dropping it closes
  the pool, then removes the container. `src/db.rs` includes `pg.rs` with `#[path]`,
  so unit and integration tests share one copy.
- Tests: `db::tests::migrations_create_the_schema_and_rerun_as_a_no_op` and
  `db::tests::constraints_hold` (name check, one open changeset per session, unique
  revision, cascade on catalog delete to every referring table, and the key's default
  catalog cleared).

## Changed

- `Cargo.toml`: `sqlx` 0.9.0 (`runtime-tokio`, `postgres`, `chrono`, `migrate`,
  `macros`; no TLS), `tokio` 1.54; dev `testcontainers-modules` 0.15.0 (`postgres`).
- `src/error.rs`: `OkfError::Database` (`From<sqlx::Error>`) and `OkfError::Migrate`
  (`From<MigrateError>`); the enum doc no longer lists git among future variants.
- `src/lib.rs`: `pub mod db;`, and the crate doc names storage.
