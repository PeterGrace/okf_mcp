# M11 Task 8: console users, teams, pickers and the unassigned view

## Added
- `pages/users.js`: the Users page (list, New user, a drawer with the user's teams, keys, grants and codes, and Delete with the reason it is refused) and `#/users/unassigned`, which lists every key, grant, sign-in code and catalog without a user or owner, each with a picker and Assign.
- `pages/teams.js`: the Teams page (list with a personal badge, New team with an owner picker, a drawer with per-member role selects and Remove, Add member, and Delete with the reason it is refused).
- `components/picker.js`: `namesOf`, `picker` and `assignControl`, shared by every user and team picker.
- `shell.js`: `canAdministerPeople()` and `refreshUnassigned()`, the count on the new Users link's `#unassigned-badge`; `#whoami` names the key's user (`alice / laptop - admin`).
- Nav links Users and Teams under Administer (`index.html`).
- Journeys: `tests/ui_e2e/users.rs` (3), `tests/ui_e2e/teams.rs` (2), two in `keys.rs` (change a key's user and assign a legacy key; change a code's user) and one in `catalogs.rs` (change an owner; a scoped admin's control is disabled). `Ui::select` in the harness and `TestServer::legacy_key` in `tests/support/server.rs`.

## Changed
- `pages/keys.js`: the stop-gap `user` text input is a required user picker in both create forms; both tables gain a User column; every key, grant (revoked included) and code drawer has Assign or Change user. A code's actor is optional ("defaults to the name").
- `pages/catalogs.js`: the stop-gap `owner` text input is a team picker; the table gains an Owner column; the edit drawer has Change owner (or Assign).
- The existing keys and catalogs journeys choose the user or owner with `ui.select`.

## Notes
- Users, teams, the owner control and the unassigned view need an admin key that reaches every catalog (plan Decision 3); for any other admin they render disabled with a note. Key and code assignment follow the managed rule.
- Pickers preselect nothing, so a credential's user is always a deliberate choice.
- The plan's Task 8 now records the shipped helpers, selectors and journeys.
