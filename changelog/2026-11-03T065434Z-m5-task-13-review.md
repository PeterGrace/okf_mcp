# M5 Task 13: review of PR #116

## Changed

- `TestServer::restart` waits for the old server to stop (its `http::serve` task,
  which ends after the poll loop and the open connections) before it starts the new
  one, within `STOP_TIMEOUT` (10 s). `serve_app` returns the task's `JoinHandle`, kept
  in a private `served` field. Before this, the old `App` could briefly overlap the new
  one on the same database, which a real pod restart does not do.
- `tests/writes.rs`: `paths` panics on an item without a string `path` instead of
  skipping it, so a change in a result's shape fails loudly.
- `concurrent_writes_from_two_connections_of_one_key_share_one_changeset` waits on a
  `tokio::sync::Barrier` before each write, so each of the three rounds sends both
  connections' writes together, instead of relying on the two loops overlapping.
