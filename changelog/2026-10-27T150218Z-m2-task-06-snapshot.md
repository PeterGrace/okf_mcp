# M2 Task 6: `okf::snapshot` (2026-10-27T15:02:18Z)

Issue #8, Task 6 of `docs/superpowers/plans/2026-10-27-okf-mcp-m2-analysis.md`. Ports
`okf.py`'s `build_docs` (961) and `_fm_fallback` (948) into an in-memory catalog snapshot
that the M2 analyses (links, oldest, sprawl, lint, search) read without touching the disk,
and that M3 will keep per catalog behind an `RwLock<Arc<Snapshot>>`.

## Added

- `rayon` 1.12.0, for reading and parsing documents in parallel.
- `src/okf/snapshot.rs`:
  - `Snapshot::build(&dyn Workspace)`: lists markdown, reads each file once and parses it
    in parallel (`par_iter` keeps `os.walk` order), then builds the path index, the
    anchors of fragment-link targets that aren't documents (a dot-directory file, say),
    the backlinks, and the secret scan of every file except `tools/okf.py` (markdown
    reuses the text already read; unreadable files are skipped, as in `okf.py`).
  - Accessors: `docs`, `get`, `concepts`, `anchors_of`, `backlinks`, `secret_findings`,
    `resolve_concept` (`/dir/x.md`, `dir/x`, `/dir/x`, `dir/x.md`).
  - `SnapshotDoc`: path, `DocKind` (concept, index, log, machinery), universal-newline
    `text`, byte-exact `raw` (rebuilt from `Doc`), `Frontmatter` (absent, parsed,
    invalid), title and aliases (`build_docs` rules, or the `_fm_fallback` port when the
    frontmatter doesn't parse), links, lowercased anchors, and `in_link_graph` (false only
    for the root `AGENTS.md`, `CLAUDE.md` and `README.md`, which `build_docs` skips).
  - `SnapshotLink` (line, raw, target, absolute, fragment, in-page, target exists, target
    is a file) and `Backlink` (source, line).
  - `fm_fallback_scalar` and `fm_fallback_list` (crate-private), with Python's `\s`
    spelled `[\s\x1c-\x1f]`.
- Tests: 15 in `snapshot::tests` (12 before review): walk order and kinds (including
  `log.md` and a nested `README.md`), text vs raw, title fallback, scalar and missing
  aliases, the fallback's `split_frontmatter` re-split, links with existence, outside and
  missing links, anchors (including a dot-directory target), backlinks, `resolve_concept`,
  secrets in every file but `okf.py`, a markdown secret found from the document text, an
  unreadable markdown file (the build fails) and an unreadable other file (skipped), and
  the fallback lists.
