# M2 Task 3: `okf::timestamp` (2026-10-27T12:55:00Z)

Issue #5, Task 3 of `docs/superpowers/plans/2026-10-27-okf-mcp-m2-analysis.md`. `okf.py`'s
`parse_ts` is `datetime.fromisoformat(s.replace("Z", "+00:00"))`; `oldest` calls it on any
`at:` string and `lint` after its `ISO_RE` check. Tasks 8 and 10 build on this module.

## Added

- `src/okf/timestamp.rs`:
  - `PyDateTime` (`Aware(DateTime<FixedOffset>)` or `Naive(NaiveDateTime)`), with
    `isoformat()` and `aware()`.
  - `IsoFormat::to_string_iso` for `DateTime<FixedOffset>`: Python's `isoformat()`
    (`.ffffff` only when non-zero, `+HH:MM`, plus `:SS` for whole-second offsets).
  - `parse_iso`: a byte-level port of CPython 3.14's C `fromisoformat`, quirks included
    (a stray character before the offset, offset fields checked only as a whole, a zero
    offset dropping its fraction, basic-form fractions without a decimal mark, `24:00`
    wrapping the date before the date is validated).
  - `is_iso_timestamp`: `okf.py`'s `ISO_RE` (Unicode `\d`, Python `$` as `\n?\z`).
- `pub mod timestamp;` in `src/okf/mod.rs`.

## Changed

- Plan: the week-date / sub-minute-offset divergence is narrowed to fractional-second
  offsets (whole-second offsets now parse, as in Python); verified fact 3 gains the C
  parser's quirks; Task 3 gets a dated `Corrected (issue #5)` note naming the shipped
  structure. The public names Tasks 8, 10 and 12 use are unchanged.

## Notes

- Divergences (module docs and `rejects_the_documented_divergences`): ISO week dates and
  offsets with a fraction of a second are rejected; naive results are returned as
  `PyDateTime::Naive` for callers to ignore rather than crash on.
- Every expected value came from Python 3.14.4. A one-off differential run (600,000
  generated strings, not committed) differed from Python only on those two divergences.
- Tests: the plan's six (with the Hegel property `isoformat_round_trips` widened to years
  1..=9999 and offsets to the second) plus `follows_cpython_quirks`,
  `rejects_the_documented_divergences`, `aware_drops_naive_values` and the Hegel property
  `parse_iso_never_panics`. One doc test on `parse_iso`.

  module doc now matches the shipped divergence (fractional-second offsets only).
- The changelog counts the plan's six tests, not five; `isoformat_round_trips` is one of
