# M9 Task 7: Changesets (issue #222)

## Added

- `GET /api/v1/changesets?catalog=`, `GET /api/v1/changesets/{handle}/diff` and
  `DELETE /api/v1/changesets/{handle}` (`src/http/api/changesets.rs`): thin
  adapters over the `list_changesets`, `pending_changes` and `discard` tools,
  so the access rules are the tools' own. An empty `?catalog=` means every
  catalog the key reaches.
- The Changesets page (`src/http/ui/js/pages/changesets.js`): the selected
  catalog's open changesets (the key's own; an admin's every key's) with
  owner, opened and last-change times, file count and idle state. A row opens
  the server-computed diff in the drawer, with Discard behind a confirmation.
- API tests: `changeset_routes_follow_the_tools_access_rules` (the access
  matrix), `a_key_lists_its_own_changesets_and_an_admin_every_keys`,
  `the_diff_shows_each_pending_file`, `the_owner_discards_its_changeset_for_good`.
- Browser journey `an_admin_discards_a_changeset_from_the_console`
  (`tests/ui_e2e/changesets.rs`): a changeset opened and edited over MCP is
  found, its diff read and discarded in the console, and the MCP
  `list_changesets` then shows none.
- `docs/operations.md` "Web console" subsection "Changesets"; one README line.

## Changed

- None outside this area. `styles.css` gains the `.diff-file` and
  `.changeset-handle` rules.

## Notes

- The diff is owner-or-admin in practice, as `ToolContext::changeset`
  enforces: a read key opens no changesets, so it sees none. Another key's
  handle answers 404, never 403, so a key cannot tell a real handle from a
  made-up one.
- The handle span is an inline block. A wrapped inline span's centre fell
  on the bare table cell, which rustwright refuses to click
  (`NotReceivingEvents`); the plan records this in a dated note.
