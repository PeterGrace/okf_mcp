# M2 Task 1: `Workspace::list_files` (2026-10-27T12:33:53Z)

Issue #3, Task 1 of `docs/superpowers/plans/2026-10-27-okf-mcp-m2-analysis.md`. The
secret scan (Task 5) walks every file in the catalog, not just markdown; M1 deferred
the method it needs.

## Added

- `Workspace::list_files`: every regular file of any type, skipping only directories
  named `.git` or `.worktrees` at any depth, in `os.walk` order (`walk_order`). This is
  `okf.py` `lint`'s secret-scan walk. Unlike `list_markdown`, other dot-directories
  (`.claude`) are included. The symlink rules of `list_markdown` apply: every listed
  path is readable through the workspace.
  - `DiskWorkspace`: a private `Listing` enum (`Markdown` | `AllFiles`) says which
    directories a walk descends into and which files it lists; `collect` takes it, and
    `listing` runs one walk and sorts it. `list_markdown` and `list_files` are both
    one-line calls to `listing`.
  - `MemWorkspace`: filters its keys with `in_skipped_directory` (any directory
    component is `.git` or `.worktrees`).

## Changed

- Both `DiskWorkspace` walks skip special files (FIFOs, sockets, devices) with a
  warning. Before, `list_markdown` listed a FIFO named `*.md`, and reading it would
  block forever. The `DiskWorkspace` listing contract now says so.

## Review follow-up (PR #17)

- `list_files` doc: a listed file's content may not be UTF-8, so reads can fail with
  `OkfError::Io` and callers must tolerate that (the Task 6 secret scan skips such a
  file, as `okf.py` skips `UnicodeDecodeError`). Only directories are pruned, so a
  `.git` file (a git worktree's link) is listed, as `os.walk` lists it.
- `DiskWorkspace` listing contract: non-UTF-8 entry names (and everything below a
  directory with one) are skipped, recorded as an accepted gap. The plan's divergence
  list gains the same line, with a dated `Corrected (issue #3)` note.
- Tests: `FILES` gains `infra/hosts/.git` (a file), which `list_files` lists; the
  symlink tests `list_markdown_does_not_traverse_symlinked_directories` and
  `listing_skips_dangling_and_outside_file_links` now check both walks.
