# M4 Task 3: `selection`: which catalogs a call acts on (2026-11-03T00:13:23Z)

Issue #67, Task 3 of `docs/superpowers/plans/2026-11-02-okf-mcp-m4-read-only-server.md`
(milestone 4, epic #64).

## Added

- `src/selection.rs` (design "Catalog selection"), pure, with no server or database:
  - `CATALOGS_HEADER` (`x-okf-catalogs`) and `CATALOGS_QUERY` (`catalogs`).
  - `Selection`: the resolved read set, never empty and without duplicates, in order;
    `catalogs()` and `write_target()` (the first name).
  - `Sources`: the tool argument, the connection's list and the server's default.
  - `connection_catalogs(&Parts)`: the `X-OKF-Catalogs` header (repeated headers read as
    one list), else `?catalogs=` on the URL (percent-decoded with `form_urlencoded`).
    Names are trimmed and empty ones dropped; a header that names nothing counts as
    unset.
  - `resolve(principal, sources, exists)`: the first source that is set wins
    (argument, connection, key default, server default); every name must exist and be
    reachable by the key, else `CatalogNotSelected` naming it; nothing set is `Refused`
    with a message naming `catalog` and the `X-OKF-Catalogs` header.
  - Seven tests: `the_first_source_that_is_set_wins`,
    `an_empty_argument_list_counts_as_unset`,
    `the_first_name_is_the_write_target_and_duplicates_collapse`,
    `an_unknown_or_ungranted_catalog_fails_naming_it`,
    `an_ungranted_server_default_is_an_error_too`, `nothing_set_means_nothing_selected`,
    `the_connection_reads_the_header_before_the_query`.
- Dependency: `form_urlencoded` 1.2.2 (already in the lock through `url`; now direct).

## Notes

- Three departures from the plan's code, none to the public API: an empty connection
  list counts as unset (as an empty argument does), so `write_target` can never index
  an empty list whatever the caller passes; a header naming nothing falls through to
  the query; and a non-ASCII header is decoded lossily rather than ignored. Ignoring it
  would have fallen back to the key's default without telling the caller, which the
  design forbids ("Catalogs are never silently dropped"); now the garbled name reaches
  `resolve` and fails naming it. Catalog names are lowercase ASCII, so no real catalog
  is lost.
- `exists` is a closure so Task 5 can pass "is this catalog loaded in the app?" without
  this module knowing about `App`.
