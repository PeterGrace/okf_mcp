# M7 Task 5: the container image and its workflow (2026-11-03T19:16:57Z)

Issue #144, Task 5 of `docs/superpowers/plans/2026-11-03-okf-mcp-m7-deployment.md`.

## Added

- `Dockerfile`: two stages.
  - Build: `rust:1.99.1-slim-bookworm` (the workstation's toolchain; bump
    both together) runs `cargo build --release --locked --bin okf-mcp` with
    BuildKit cache mounts for the crate registry and `target/`.
  - Runtime: `debian:bookworm-slim` with `ca-certificates` only, the binary
    at `/usr/local/bin/okf-mcp`, user uid 10001, `EXPOSE 8080`,
    `ENTRYPOINT ["/usr/local/bin/okf-mcp"]` and `CMD ["serve"]`. No git and
    no OpenSSL.
- `.dockerignore`: keeps `target`, `.git`, `.worktrees`, `.claude`,
  `.github`, `changelog`, `docs` and `tests` out of the build context.
- `.github/workflows/image.yml`: builds the `Dockerfile` and pushes
  `ghcr.io/petergrace/okf-mcp` with the built-in `GITHUB_TOKEN`
  (`packages: write`).
  - **When:** on a pushed `v*` tag, and on manual dispatch.
  - **Tags:** `<version>` from a `v*` tag (`v0.7.0` gives `0.7.0`) and
    `sha-<short>` on every run; a dispatch on `main` publishes
    `sha-<short>` only. No `:latest` (`flavor: latest=false`): deployments
    pin a version.
  - **Actions:** pinned to full commit SHAs, the version in a comment.
  - **Not CI:** it runs no gates; they stay local.

## Changed

- `Cargo.toml`, `Cargo.lock`: version `0.1.0` to `0.7.0`;
  `okf-mcp --version` prints `okf-mcp 0.7.0`.

## Notes

- Local build: 42 s from a cold cargo cache on a 32-core machine; the image
  is 157 MB on disk (38.7 MB compressed content). `/healthz` against a
  throwaway Postgres answered `{"database":"ok","catalogs":0}`; `clock`
  arrives with Task 3.
- `actionlint` is not installed here; the workflow was checked with a YAML
