# M3 Task 14: follow okf.py 481357b, skipping install/, and docs/ and tests/ at the root (2026-11-02T15:58:51Z)

Issue #50, Task 14 of `docs/superpowers/plans/2026-11-02-okf-mcp-m3-storage.md`. The
catalog adopted the okf-catalog-template in `pg_knowledge_catalog` commit `481357b`
(2026-10-28), and its `okf.py` changed with it: `walk_md` no longer walks the template's
setup machinery (`install/`, at any depth) or its development docs and tests (`docs/` and
`tests/`, at the catalog root only), and `new_concept_path` refuses those as a concept's
first component. The port still walked them, so live parity failed 4 of 6 (7 extra
`install/**` documents and 2 extra broken links on the real catalog).

## Added

- `okf::paths::SKIP_DIRS` (`.git`, `.claude`, `install`) and `okf::paths::SKIP_TOP`
  (`docs`, `tests`), mirroring `okf.py`'s constants of the same names.
- Fixtures: `install/setup.md`, `docs/plan.md`, `tests/case.md` and
  `markdown/install/nested.md`, each with a broken link that would show in the goldens
  if it were walked, and `markdown/docs/nested.md`, which is walked (`SKIP_TOP` is
  root-only).
- Tests: `mem_markdown_walk_skips_template_machinery`,
  `disk_markdown_walk_skips_template_machinery` (one shared assertion for both
  workspaces), `listing_lists_checks_each_component` (workspace); new cases in
  `new_concept_path_rules` (paths).

## Changed

- The markdown walk (`Workspace::list_markdown`) in both `DiskWorkspace` and
  `MemWorkspace` skips `SKIP_DIRS` at any depth and `SKIP_TOP` at the root, beside
  dot-directories as before. Both now apply one rule, `Listing::descends_into(name,
  at_root)`: the disk walk per directory, the in-memory one per path component
  (`Listing::lists`), which also replaced the `in_dot_directory` and
  `in_skipped_directory` helpers.
- `new_concept_path` refuses a first component in `SKIP_DIRS`, `SKIP_TOP` or `tools`
  (`okf.py`'s `SKIP_DIRS | SKIP_TOP | {"tools"}`). `infra/docs/x` is still allowed.
- Goldens regenerated from the current `okf.py` (sha256 `3ee65c4d...`, in
  `tests/golden/SOURCE`). Regenerated before the new fixtures, only `SOURCE` changed;
  with them, the only golden changes are the walked `markdown/docs/nested.md` (one more
  concept, orphan, dead end, index drift, sprawl entry and its lint warnings). The broken
  link count is unchanged, so none of the skipped fixtures is read by `okf.py` either.

## Removed

- `okf::paths::MACHINERY_DIRS`, replaced by `SKIP_DIRS`, `SKIP_TOP` and `tools` in the
  private `is_machinery`.

## Notes

- The secret scan's walk (`list_files`) is unchanged: `okf.py`'s lint still walks every
  file outside `.git` and `.worktrees`, `install/` and `docs/` included. No other
  `okf.py` function uses `SKIP_DIRS` or `SKIP_TOP`.
- Live parity on the real catalog passes 6 of 6 again.
