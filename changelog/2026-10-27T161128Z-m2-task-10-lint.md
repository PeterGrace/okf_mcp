# M2 Task 10: `okf::analysis::lint` (2026-10-27T16:11:28Z)

Issue #12, Task 10 of `docs/superpowers/plans/2026-10-27-okf-mcp-m2-analysis.md`. Ports
`okf.py`'s `check_ts` (1815) and `lint` (1835-1972) over the snapshot, so `lint` gives
the same JSON as `okf.py lint --json`. Git commit times are an input (decision 2).

## Added

- `src/okf/analysis/lint.rs`:
  - `lint(&Snapshot, now, Option<&CommitTimes>) -> LintReport`: frontmatter presence
    and parse errors, `type`/`title`/`description`, `status`, the `generated`,
    `verified`, `reviewed`, `stale_after` and `sources` shapes and timestamps
    (`check_ts`: ISO shape, validity, UTC, two minutes of future slack), index rules
    (folder indexes without frontmatter, the root's `okf_version`),
    `generated-after-commit`, the link report's findings, sprawl warnings and the
    snapshot's secret findings, each list sorted stably by (file, line, rule).
  - `CommitTimes::new(times, dirty)`: `last_commit_times()`'s return value; `None`
    means git is unavailable and skips the commit check.
  - Documents (and their sprawl scores) are checked in parallel with `rayon`, collected
    in walk order so ties keep `okf.py`'s discovery order.
- `src/okf/analysis/testdata/lint-mini.json` and `lint-quirks.json`: `okf.py`'s
  `lint()` output for the two unit-test catalogs, "now" and commit times pinned.
- Tests: 6 in `analysis::lint::tests`: the plan's four, plus `quirks_match_okf_py` and
  `root_index_parse_errors_are_reported`.

## Changed

- `src/okf/analysis/mod.rs`: `pub mod lint;`.
- The plan's Task 10: a dated correction note describing the shipped structure, and the
  file map and Task 10 file list name `lint-quirks.json`.

## Notes

- Divergence (in the module docs): a list or mapping `status` is reported with its
  `repr`; `okf.py` raises `TypeError` (unhashable) and its lint crashes. Confirmed by
  running `okf.py` on both shapes.
- Both slack checks compare differences (`ts - now > FUTURE_SLACK`) so they cannot
  overflow; `committed + Duration` would panic near year 9999.
- Parity (values; `json.dumps` escapes non-ASCII where serde_json writes it raw):
  equal to `okf.py lint --json` on `tests/fixtures/catalog` (30 errors, 86 warnings,
  with `okf.py`'s own commit times; also with none, and with synthetic commit times that
  fire `generated-after-commit`), on `pg_knowledge_catalog` with its real git times (0
  errors, 3 sprawl warnings), and on both unit-test catalogs. A release build takes about
  15 ms for snapshot plus lint on `pg_knowledge_catalog`; `okf.py lint --json` takes
  0.23 s.
