# M5 Task 7: fourth review of PR #111 (2026-11-03T050748Z)

Answers Brooke's fourth review of PR #111 (issue #96).

## Changed

- **`is_broken_overlay` now matches positively.** It holds for `OkfError::InvalidPath`
  only, the one form `build_overlay` reports an overlay failure in. Before, it held
  for any error that was neither internal nor `Busy`, so a non-internal variant added
  to `view`'s path later would have silently become a skipped catalog. Every other
  error now propagates.
- **`build_overlay` also attributes snapshot failures to the changeset.**
  - A pending `.md` whose bytes are not UTF-8 made `Snapshot::build` fail with `Io`.
    That is internal, so every read on the connection was masked as "internal error"
    and `search` could not skip it.
  - `in_changeset` now maps an `Io` to an `InvalidPath` at that path:
    `<path>: <cause>, in pending changeset N; discard <path> or the changeset`.
  - The published files already built into the base snapshot, so such a failure comes
    from the pending entries.
- **New test:** `a_pending_md_that_is_not_utf8_names_the_changeset`.
- **Plan:** Task 7's Corrected note describes the positive match and the `Io` mapping.
- **Design:** names the non-UTF-8 case.
