# Agentic development tools in `tools/agentic/`

## Added
- `tools/agentic/gate.sh`: runs `fmt`, `lint`, `test`, `test-ui` or a narrow `cargo test`. Every gate has a hard timeout (5m, 30m, 75m, 60m and 15m respectively, each configurable). The heavy gates also take a lock in the shared git directory, so worktrees don't run them at once. Exit 124 means a test hung, and the script prints how to find it.
- `tools/agentic/watch-review.sh`: waits for the review bot to review a PR's current head, re-triggers it once if it is silent, and gives up after 30 minutes showing the bot's comments.
- `tools/agentic/merge-reviewed.sh`: merges only when the bot has reviewed the current head, every bot thread has a reply, and the PR is CLEAN.
- `tools/agentic/watchdog.sh`: the coordinator-side hang detector. It exits when a test or gate process in this repository runs past its limit (20 min for test binaries, 80 min for gates), whether or not a PR exists yet.
- `tools/agentic/brief-common.md` and `tools/agentic/lessons.md`: the shared rules for implementation agents, and the rules learned from real review findings in milestone 12.
- `tools/agentic/README.md`, plus a root `AGENTS.md` telling every agent to use these tools instead of writing its own.

## Notes
- These began as session-local coordinator scripts during milestone 12. They were made repo-agnostic: the repository comes from `gh`, the reviewer and its re-trigger command are configurable, and paths come from git.
- The timeouts and the watchdog came from an incident: a race test held a row lock with no timeout and stalled task 10b (#320) for about 12 hours before anyone noticed.
